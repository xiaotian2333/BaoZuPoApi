# 门锁

> **门锁设备**专用：`/ymSdk` 门锁指令（写卡/指纹/密码/同步/集中器下行）+ `/v1/client` 门卡指纹业务 + `/v1/admin` 门锁管理。
> 调用约定（加密/鉴权/URL 形态）见 [README](./README.md)，其他设备文档可点击上方导航。

## 1. 门锁指令 `/ymSdk/*`

云端：`POST https://bzp.iyunmu.com/bzp_backup/ymSdk/<指令名>`（无尾斜杠）。门卡/指纹/密码均以 SN 指定目标门锁。
