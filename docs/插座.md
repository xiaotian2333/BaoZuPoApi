# 插座

> **插座类设备**（智能插座/公共插座/从表插座）专用接口。
> 调用约定（加密/鉴权/URL 形态）见 [README](./README.md)，其他设备文档可点击上方导航。

云端：`/ymSdk/<指令名>` 为远程插座指令，`/v1/admin/*` 为插座管理。

### 1.1 远程插座指令（4）

| 模块文件 | 云端接口 | 用途 |
|---|---|---|
| `remote_clean_socket.js` | `POST /ymSdk/remote_clean_socket` | 远程插座指令-清除告警 |
| `remote_force_off_socket.js` | `POST /ymSdk/remote_force_off_socket` | 远程插座指令-强制断电 |
| `remote_read_socket.js` | `POST /ymSdk/remote_read_socket` | 远程插座指令-抄读 |
| `remote_set_socket.js` | `POST /ymSdk/remote_set_socket` | 远程插座指令-设置参数 |

### 1.2 公共插座（5）

| 模块文件 | 云端接口 | 用途 |
|---|---|---|
| `bind_public_socket.js` | `POST /v1/admin/bind_public_socket/` | 绑定公共插座 |
| `edit_public_socket_name.js` | `PUT /v1/admin/edit_public_socket_name/` | 修改公共插座名 |
| `get_public_socket_list.js` | `GET /v1/admin/get_public_socket_list/` | 公共插座列表 |
| `public_socket_bind_gateway.js` | `POST /v1/admin/public_socket_bind_gateway/` | 公共插座绑定网关 |
| `unbind_public_socket.js` | `POST /v1/admin/unbind_public_socket/` | 解绑公共插座 |

### 1.3 从表插座（5）

| `delete_slave_socket.js` | `POST /v1/admin/delete_slave_socket/` | 删除从表插座 |
| `edit_slave_socket_name.js` | `PUT /v1/admin/edit_slave_socket_name/` | 修改从表插座名 |

| `replace_slave_socket.js` | `PUT /v1/admin/replace_slave_socket/` | 更换从表插座 |
