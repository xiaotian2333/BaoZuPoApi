# 其他设备

> **非电表/水表/门锁/插座/蓝牙**的其他设备与子系统：集抄集中器网关、Mesh 组网工具、以及充电（电瓶车充电桩）计费服务。
> 调用约定（加密/鉴权/URL 形态）见 [README](./README.md)，其他设备文档可点击上方导航。

## 1. 集抄网关管理

集中器本身的管理（绑定/解除/信息/设备列表），不含集中器下行电表指令（见 [电表](./电表.md) §2.3）。

### 1.1 集抄网关（4）

| 模块文件 | 云端接口 | 用途 |
|---|---|---|
| `collector_bind_device.js` | `POST /v1/admin/collector_bind_device/` | 集中器绑定设备 |
| `collector_device.js` | `GET /v1/admin/collector_device/` | 集中器设备列表 |
| `collector_info.js` | `GET /v1/admin/collector_info/` | 集中器信息 |
| `collector_relieve_device.js` | `PUT /v1/admin/collector_relieve_device/` | 集中器解除设备 |

## 2. Mesh 组网

Mesh 网络拓扑绑定与设备列表（Mesh 电表/水表指令见对应文档）。

### 2.1 Mesh 组网（4）

| 模块文件 | 云端接口 | 用途 |
|---|---|---|
| `mesh_bind_device.js` | `POST /ymSdk/mesh_bind_device` | Mesh组网-绑定设备 |
| `mesh_bind_share_device.js` | `POST /ymSdk/mesh_bind_share_device` | Mesh组网-绑定共享设备 |
| `mesh_device_list.js` | `GET /v1/admin/mesh_device_list/` | Mesh设备列表 |
| `mesh_share_device_list.js` | `GET /v1/admin/mesh_share_device_list/` | Mesh共享设备列表 |

## 3. 充电服务

简捷充电（扫码充电桩）计费、规则、记录。注意与「电表电量计费」区分。

### 3.1 充电服务（11）

| 模块文件 | 云端接口 | 用途 |
|---|---|---|
| `add_simple_charge_rule.js` | `POST /v1/admin/add_simple_charge_rule/` | 添加简易充电规则 |
| `delete_charge_rule.js` | `POST /v1/admin/delete_charge_rule/` | 删除充电规则 |
| `edit_simple_charge.js` | `POST /v1/admin/edit_simple_charge/` | 修改简易充电 |
| `edit_simple_charge_rule.js` | `POST /v1/admin/edit_simple_charge_rule/` | 修改简易充电规则 |
| `get_charge_record_list.js` | `GET /v1/admin/get_charge_record_list/` | 充电记录列表 |
| `get_simple_charge_config.js` | `GET /v1/admin/get_simple_charge_config/` | 简易充电配置 |
| `get_simple_charge_rule_list.js` | `GET /v1/admin/get_simple_charge_rule_list/` | 简易充电规则列表 |
| `reset_charge_bill_payer.js` | `POST /v1/admin/reset_charge_bill_payer/` | 重置充电账单付款人 |
| `set_charge_enable.js` | `POST /v1/admin/set_charge_enable/` | 启用/停用充电 |
| `set_charge_expire_off.js` | `POST /v1/admin/set_charge_expire_off/` | 充电到期断电 |
| `skip_current_charge.js` | `POST /v1/admin/skip_current_charge/` | 跳过当前充电 |
