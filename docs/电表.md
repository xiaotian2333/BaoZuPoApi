# 电表（电量计费表）

> 直接操作与读取**电量计费表**的接口：`/ymSdk` 远程指令（含多费率、共享/从表、集抄、Mesh）+ `/v1/client` 电表业务 + `/v1/admin` 电价模板与电表运维。
> 调用约定（加密/鉴权/URL 形态）见 [README](./README.md)，其他设备文档可点击上方导航。

## 6. 已验证模块详解

### 6.1 `remote_read_meter`（已抓包验证）

**请求**：`{ sn, isPay }`　**编程式**：`api.remote_read_meter({ sn, isPay: false })`　**本地**：`POST /remote/read/meter`

**响应**（`body.data`，真实样例已脱敏）：

```json
{
  "sn": "xxx",
  "cmdType": "8016",
  "ver": "1",
  "params": { "cmd": "1" },
  "callback": "http://<device_host>:7000/ymSdk/remote_read_meter_back/xxx",
  "sign": "xxx",
  "access_key": "xxx",
  "timeStamp": 1750000000
}
```

| 字段 | 说明 |
|---|---|
| `cmdType` | 指令类型（`8016` 抄表类） |
| `params` | 指令参数（`cmd:"1"` 抄读状态） |
| `callback` | 指令执行结果回调地址 |
| `sign` / `access_key` / `timeStamp` | 下发设备时携带的签名 / 通道密钥 / 时间戳 |

### 6.2 `client_device_info`（已抓包验证）

请求 `{ sn }`；响应 `body.data` 关键字段：`surplusValue`（剩余金额/电量）、`basisPrice`（基础电价）、`switchStatus`（开关）、`multi_fun_info`（电压/电流/功率/频率）、`pay_enable` / `pay_limit`（缴费相关）、`payee`（收款方）、`wx_fee/icbc_fee/zfb_fee`（各渠道手续费率）。

### 6.3 `client_link_device`（已抓包验证）

请求 `{ sn }`；响应 `body.data.link_device_list`：该电表绑定的联动设备列表。
