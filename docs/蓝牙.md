# 蓝牙

> **蓝牙设备**（邻近BLE、蓝牙钥匙、扫码蓝牙配置）相关接口。
> 调用约定（加密/鉴权/URL 形态）见 [README](./README.md)，其他设备文档可点击上方导航。

蓝牙钥匙（`*_ble_key`）用于经由 BLE 连接门锁/手表等设备的开锁凭据管理；门锁专用 BLE 接口见 [门锁](./门锁.md)。

### 1.1 蓝牙列表 / 扫描 / 配置（5）

| 模块文件 | 云端接口 | 用途 |
|---|---|---|
| `client_get_nearby_ble_dev.js` | `POST /v1/client/client_get_nearby_ble_dev/` | 附近蓝牙设备 |
| `get_ble_dev_list.js` | `POST /ymSdk/get_ble_dev_list` | 获取蓝牙设备列表 |
| `get_nearby_ble_dev.js` | `POST /v1/admin/get_nearby_ble_dev/` | 附近蓝牙设备 |
| `get_scan_ble_config.js` | `POST /v1/admin/get_scan_ble_config/` | 扫码蓝牙配置 |
| `set_ble_devlist.js` | `POST /ymSdk/set_ble_devlist` | 设置蓝牙设备列表 |

### 1.2 蓝牙钥匙（4）

| 模块文件 | 云端接口 | 用途 |
|---|---|---|
| `add_ble_key.js` | `POST /v1/admin/add_ble_key/` | 添加蓝牙钥匙 |
| `delete_ble_key.js` | `POST /v1/admin/delete_ble_key/` | 删除蓝牙钥匙 |
| `edit_ble_key.js` | `PUT /v1/admin/edit_ble_key/` | 修改蓝牙钥匙 |
| `get_ble_key_list.js` | `GET /v1/admin/get_ble_key_list/` | 蓝牙钥匙列表 |
