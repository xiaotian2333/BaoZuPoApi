# 水表

> **水费计量表**专用接口：远程水表充值/断电/清警、Mesh 水表、母表配置与绑定。
> 调用约定（加密/鉴权/URL 形态）见 [README](./README.md)，其他设备文档可点击上方导航。

## 1. 远程水表指令 `/ymSdk/*`

云端：`POST https://bzp.iyunmu.com/bzp_backup/ymSdk/<指令名>`（无尾斜杠），参数通常带 `sn`。

### 1.1 远程水表（3）

| 模块文件 | 云端接口 | 用途 |
|---|---|---|
| `water_remote_clean.js` | `POST /ymSdk/water_remote_clean` | 远程水表-清除告警 |
| `water_remote_force_off.js` | `POST /ymSdk/water_remote_force_off` | 远程水表-强制断电 |
| `water_remote_pay.js` | `POST /ymSdk/water_remote_pay` | 远程水表-充值 |

### 1.2 指令等待与回调（2）

| 模块文件 | 云端接口 | 用途 |
|---|---|---|
| `water_pay_check.js` | `POST /ymSdk/water_pay_check` | 水表支付校验 |
| `water_wait_cmd.js` | `POST /ymSdk/water_wait_cmd` | 水表指令等待状态 |

`water_wait_cmd` / `water_pay_check` 用于水表充值/指令的状态轮询与支付校验。

## 2. Mesh 组网水表

```
mesh_water_set        Mesh 组网-水表设置
mesh_water_clean      Mesh 组网-水表清除告警
mesh_water_bind_elec  Mesh 组网-水表绑定电表（水电联动表）
```

### 2.1 Mesh 水表（3）

| 模块文件 | 云端接口 | 用途 |
|---|---|---|
| `mesh_water_bind_elec.js` | `POST /ymSdk/mesh_water_bind_elec` | Mesh组网-水表绑定电表 |
| `mesh_water_clean.js` | `POST /ymSdk/mesh_water_clean` | Mesh组网-水表清除告警 |
| `mesh_water_set.js` | `POST /ymSdk/mesh_water_set` | Mesh组网-水表设置 |

## 3. 母表与绑定

### 3.1 母表 / 绑定（2）

| 模块文件 | 云端接口 | 用途 |
|---|---|---|
| `mesh_bind_water_list.js` | `GET /v1/admin/mesh_bind_water_list/` | Mesh水表绑定列表 |
| `mother_water_config.js` | `POST /ymSdk/mother_water_config` | 母表水表配置 |

## 4. 注意事项

- 水表充值走 `water_remote_pay`（云端预生成充值指令），与电表充值（`/v1/client` 计费业务，见 [通用](./通用.md)）机制不同。
- `remote_pay`（刷卡支付）为 MQTT 指令非 HTTP，未建模块。
