# 通用

> **所有设备都适用**的跨设备业务接口：账户/登录/银行卡、公告/合同/租约/转账、房间管理、管理端账号权限、扫码登录、支付渠道（adapay）以及**计费业务（充值/账单/余额/抄表记录，水电共用同一套）**。
> 调用约定（加密/鉴权/URL 形态）见 [README](./README.md)，其他设备文档可点击上方导航。
